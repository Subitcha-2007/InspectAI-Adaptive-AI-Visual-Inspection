# InspectAI — Adaptive AI Visual Inspection

A computer-vision based AI visual inspection system for automated quality analysis.

## Features

- AI-based visual inspection
- Defect detection
- Quality analytics
- PASS/FAIL analysis
- Synthetic data support
- Inspection history
- Hardware monitoring
- Demo Mode
- Live Mode
- Camera/ESP32 integration where configured
- Printable/downloadable quality reports
